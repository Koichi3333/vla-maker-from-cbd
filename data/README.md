# data/

| Path | What | Source | Terms |
| --- | --- | --- | --- |
| `video_reach/` | LeRobot dataset, 671 episodes, 117-d state/action at 20 fps, captions, per-frame object states in `objects/`. **No images**: the observation video is re-rendered on the VM by `vla/render_with_objects.py` | 13 real clips: the author's own iPhone videos (fixed camera), converted to CBD (MediaPipe pose, SMPL fit via ROMP for the torso, SAM 2 for objects) and quality-gated. 658 synthetic reaches: closed-loop rollouts of an earlier model with inference-time guidance, cut to the reaching segment (647 train, 11 held out). `meta/split.json`, `meta/synth_report.json` | Non-commercial research (SMPL-derived torso; synthetic part generated by a model trained on HumanML3D) |
| `eval/object_eval_heldout.json` | 7 held-out scenes with object positions (original / shifted / mirrored) and H-4 offsets | Built by `vla/object_eval_spec.py` from the real clips | Same as above |
| `eval/object_eval_train.json` | 7 train-side scenes (same format) | Same | Same |
| `eval/object_eval_vlm_box.json` | The 7 held-out scenes with `vlm_goal`: the goal the VLM chose, pushed half the object size along the camera ray (`vla/vlm_goal_depth.py goals --method box`) | Gemini Robotics-ER answers (2026-10-11) | Same |
| `stats/statistics.json` | Normalization statistics (q01/q99 per group) of `checkpoint-47000` | HumanML3D train split | Same |

The only person in the real clips is the author. Only skeleton rotations and object states are stored;
no frames of the original video are included.

**Want a dataset you can use commercially?** It has to come from recordings whose rights you hold, converted
without SMPL-licensed components. Contributing such CBD clips is one of the most useful things you can do
(see [CONTRIBUTING.md](../CONTRIBUTING.md)).
